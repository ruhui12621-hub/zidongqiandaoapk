森空岛 Token 解析 · 操作导航

登录森空岛 → 复制 Token 页面 JSON → 粘贴到下方自动解析 → 复制 Token → 更新华为云函数。

1

登录森空岛

先在当前浏览器登录森空岛账号，保持登录状态。

打开森空岛官网 https://www.skland.com/
2

打开 Token 页面并复制全部内容

保持登录状态打开下面链接，页面会显示一段 JSON 文本。全选并复制页面上的全部内容。

打开 Token 获取页面 https://web-api.skland.com/account/info/hg
3

粘贴 JSON，自动解析并复制 Token

把上一步复制的内容粘贴到下面。页面会自动提取 data.content；如果你直接粘贴了 Token 字符串，也会原样识别。

解析结果 等待粘贴…
4

更新华为云函数

打开华为云函数控制台，编辑 INPUT_HYPERGRYPH_TOKEN.txt，粘贴 Token 后点击“部署代码”。

打开华为云函数控制台 https://console.huaweicloud.com/functiongraph
说明
  • 本页面不会联网请求森空岛接口，只在你本地解析粘贴进来的文本，所以可以放心托管或本地打开。
  • 由于浏览器的跨域与 Cookie 限制，网页无法自动替你拉取 Token JSON，手动复制粘贴这一步无法省略。
  • Token 等同于登录凭证，请勿分享。多账号时每行一个 Token 填入云函数。
  • 如果复制按钮无效，通常是浏览器不允许非 HTTPS 页面使用剪贴板 API，可手动长按选中复制。

本页面仅做本地文本解析，不收集、不存储任何信息。
